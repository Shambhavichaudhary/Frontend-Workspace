about daily motivation

Daily Motivation is a small website created as a part of my HTML and CSS learning journey. This project is built to practice basic CSS styling concepts such as colors, fonts, text alignment, spacing, text decoration, and other text properties.

The main purpose of this website is not to create a fully functional motivational platform, but to apply the concepts I am currently learning in a simple and creative way.
